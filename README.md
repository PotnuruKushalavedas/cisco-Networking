----------------------------------------------------------------------
Universal Cisco CLI Configuration Steps
**Step 1: Enter Privileged EXEC Mode**<br>
enable<br><br>
Step 2: Enter Global Configuration Mode<br>
configure terminal<br><br>
Step 3: Select the Interface<br>
interface <interface-name><br><br>
interface gigabitEthernet 0/0<br><br>
Step 4: Configure the IP Address<br>
ip address <ip-address> <subnet-mask><br><br>
**Step 5: Enable the interface**<br>
`Router(config-if)# no shutdown`<br><br>
